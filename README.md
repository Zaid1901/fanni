# فنّي (Fanni)

تطبيق Flutter بيوصل الزبون بالفني المناسب. هاي نسخة الواجهة (frontend) ببيانات تجريبية، بدون backend.

## التشغيل

بدك Flutter 3.50 أو أحدث.

```bash
flutter pub get
flutter run -d chrome
```

## حسابات تجريبية

حسابين جاهزين، وهميين وبدون بيانات حقيقية:

| الدور | الإيميل | كلمة المرور |
|---|---|---|
| زبون (ليث حداد) | `zaboon@fanni.demo` | `fanni2026` |
| فني (يوسف عيسى) | `fanni@fanni.demo` | `fanni2026` |

أو اضغط "دخول كزبون" / "دخول كفني" بصفحة الدخول، وبيدخلوك على نفس الحسابين.
الحسابات اللي بتنعمل من "سجّل الآن" بتضل لحد ما تعيد تحميل الصفحة.

## ملاحظة عن الـimports

من Flutter 3.47 صار Material بباكج لحاله. استخدموا:

```dart
import 'package:material_ui/material_ui.dart';
```

بدل `package:flutter/material.dart`.

## شو فيه

- Onboarding، تسجيل دخول، وإنشاء حساب مع اختيار الدور (زبون أو فني).
- الرئيسية، والبحث بفلاتر الصنعة والمدينة، وملف الفني مع شهادة المزاولة.
- طلب سعر من فني، ومتابعة الطلب: سعر تقريبي، موافقة، إنجاز، تقييم.
- نشر مشكلة مع صورة. بدون مزاد: الفنيين بيضغطوا "أنا مهتم" بدون سعر، والزبون بيختار حسب التقييم والشغل السابق.
- صفحة للفني يضيف فيها صور شغله ويشوف تقييمات الزباين.
- "وضع الفني" من تبويب حسابي، لتجربة التطبيق كفني.

## بنية المجلدات

- `lib/theme`: الألوان والـtheme.
- `lib/data`: الـmodels والبيانات التجريبية (`mock_data.dart`).
- `lib/widgets`: العناصر المشتركة.
- `lib/screens`: الشاشات.
- `docs`: نسخة الويب المبنية لـGitHub Pages. لا تعدّلوها باليد، بتتولّد بهالأمر:

```bash
flutter build web --base-href /fanni/ -o docs
```

## اللي لسا مش موجود

- Backend: كل البيانات بالذاكرة وبتنمسح عند إعادة التشغيل.
- رد الفني بالسعر واهتمام الفنيين محاكاة بأزرار مكتوب عليها "للعرض فقط".
- الدفع، والاتصال، ورفع شهادة المزاولة.
